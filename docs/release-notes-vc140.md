# Release notes — v3.1.22 (build 140)

Paste into App Store Connect › "What's New in This Version" and Play Console ›
"Release notes". Keep each under Apple's 4 000-character limit.

## 中文 (zh-Hans)

```
「附近」更好用,也更私密。

• 直接可用 — 打开「附近」就能看到附近的人,不用每次先签到
• 只显示大致距离 — 1 公里内 / 1–5 公里 / 5–10 公里 / 10 公里以上,不显示地图,也不会公开你的精确位置
• 首次进入会说明你将出现在别人的「附近」列表中,可以当场选择关闭
• 随时可在「设置 › 隐私 › 在「附近」显示我」中开关
• 长按任意卡片即可屏蔽或举报

修复了部分用户「附近」列表为空的问题。
```

## English (en-US)

```
Nearby is easier to use — and more private.

• Just works — open Nearby and see people around you, no check-in step
• Approximate range only — under 1 km / 1–5 km / 5–10 km / over 10 km. No map, and your precise location is never shared
• A one-time explanation on first use tells you that you'll appear in other people's Nearby list, and lets you turn it off right there
• Change it any time in Settings › Privacy › "Show me in Nearby"
• Long-press any card to block or report

Fixes an issue where Nearby could appear empty for some members.
```

## Bahasa Melayu (ms)

```
Berdekatan kini lebih mudah digunakan — dan lebih peribadi.

• Terus berfungsi — buka Berdekatan dan lihat orang di sekeliling anda, tanpa langkah daftar masuk
• Julat anggaran sahaja — bawah 1 km / 1–5 km / 5–10 km / lebih 10 km. Tiada peta, dan lokasi tepat anda tidak pernah dikongsi
• Penerangan sekali sahaja pada penggunaan pertama memberitahu anda bahawa anda akan muncul dalam senarai Berdekatan orang lain, dan membolehkan anda mematikannya terus
• Tukar bila-bila masa di Tetapan › Privasi › "Tunjukkan saya dalam Berdekatan"
• Tekan lama mana-mana kad untuk menyekat atau melaporkan

Membaiki isu di mana Berdekatan kelihatan kosong bagi sesetengah ahli.
```

## 한국어 (ko)

```

일부 회원에게 '내 주변' 목록이 비어 보이던 문제를 수정했습니다.
```
